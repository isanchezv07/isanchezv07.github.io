Mi portafolio personal construido con un enfoque en la eficiencia, el minimalismo y la automatización. Este sitio no solo muestra mi trabajo, sino que sirve como una muestra de mi capacidad técnica para integrar APIs y arquitecturas web modernas.

🔗 **Visítalo en:** [isanchezv07.github.io](https://isanchezv07.github.io)

## 🚀 Características Principales

- **Automatización Total de Proyectos:** Integración directa con la API de GitHub para extraer repositorios públicos, métricas (estrellas, forks) y tecnologías utilizadas en tiempo real.
- **Diseño de Élite:** Estética "Dark Mode" de alta gama con efectos de rejilla técnica, resplandores sutiles y micro-interacciones refinadas.
- **Arquitectura de Islas (Astro):** Rendimiento máximo con tiempos de carga casi instantáneos gracias a la generación de sitios estáticos (SSG).
- **Stack Técnico Discreto:** Un arsenal técnico categorizado utilizando iconos SVG de alta fidelidad con un estilo monocromático profesional.
- **Totalmente Responsivo:** Experiencia optimizada para cualquier dispositivo, desde móviles hasta monitores ultra-wide.

## 🛠️ Stack Tecnológico

- **Framework:** [Astro 4.0](https://astro.build/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Iconografía:** SVGs locales personalizados
- **Despliegue:** [GitHub Actions](https://github.com/features/actions)

## 💻 Desarrollo Local

Si deseas clonar este proyecto y ejecutarlo en tu máquina:

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Construir para producción:**
   ```bash
   npm run build
   ```

## ⚙️ Configuración de Automatización

El sistema de proyectos se alimenta de la API pública de GitHub. Para personalizar los proyectos que aparecen:
- El sitio filtra automáticamente los **forks**.
- Prioriza los repositorios con más **estrellas** y actividad reciente.
- Extrae las tecnologías de la sección **Topics** de cada repositorio en GitHub.
